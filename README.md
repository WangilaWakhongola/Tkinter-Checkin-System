# Check-In System 

A simple event check-in desktop app built with **Python** and **Tkinter**.

## Features

- **Register** attendees with name, ID/badge number, and optional email
- **Check-In** by name or ID with duplicate prevention (one check-in per day)
- **Records** tab showing all check-ins with timestamps
- Data stored locally in `data.json` — no database needed
